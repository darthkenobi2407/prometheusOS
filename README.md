# PrometheusOS

This is basically a small browser-based desktop environment prototype.

## Run locally

SO first serve this folder with any static web server then open its local URL so this makes browser storage behave consistently you can also deploy the folder to Vercel as a static site.

## Current features 

- A local account setup and login screen
- Notes apps that saves in browser storage
- Simple simulated terminal(not real shell commands obv)
- An about this computer window
- "My Site" window that shows my projects and stuff i plan to do later
-  a macOS inspired menu bar and windows and dock
- an 'F1' app that shows times and race results for championships


this is just a simple hobby project made for stardance :)
